## The joke

> The meeting ended early, so we used the saved time to schedule a meeting about the time we saved.

## How it works

`main.py` (Python standard library only, no network, deterministic) writes the line to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`), asserting the 1–200 character range.

```sh
python3 main.py
```
